# files.bsns.ru

Публичное статическое файловое хранилище BZN. Runtime-каталоги `templates/` и `users/` не добавляются в историю Git.

Личные images/templates/styles/options хранятся вне публичного сайта. Resource API проверяет короткоживущие подписанные разрешения; браузер передаёт байты напрямую ему. Открытый `users/` содержит только общие HTML-входы публичных профилей и портфолио: `/users/{slug}/` и `/users/{slug}/portfolio/`. Файлов пользователя в этом публичном каталоге нет.

Этот домен не исполняет PHP и может использоваться как статический сайт/CDN. Межсерверный Resource API должен работать на PHP/VPS-домене и обращаться к этому хранилищу через свой внутренний адаптер; PHP entrypoint в этот checkout не размещать.

## Шаблоны

- `templates/*.png` — переносимые BZN-проекты с превью и JSON-метаданными внутри PNG.
- `templates/*.bzn.json` — поддерживаемый запасной формат проекта.
- `templates/manifest.json` — подписи и порядок карточек; отсутствующие файлы автоматически исключаются.
- `templates/manifest.php` — динамически сканирует папку и возвращает актуальный список. Новые поддерживаемые файлы появляются даже без ручной записи в JSON.

Целевой серверный каталог: `/www/files.bsns.ru/templates`.

Общие шаблоны сохраняют прежний Resource API. Личные файлы читаются браузером напрямую через подписанный файловый API с разрешённым CORS origin; угаданный путь или имя пользователя не дают доступа.
