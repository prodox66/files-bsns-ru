# files.bsns.ru

Публичное файловое хранилище BZN. Репозиторий хранит переносимый Resource API; runtime-каталоги `templates/` и `users/` не добавляются в историю Git.

## Resource API

- `resource-api.php` — единая межсерверная точка чтения логических ресурсов.
- Вызывающий сайт передаёт только `type`, `scope`, непрозрачный `owner` и действие; физический путь не возвращается.
- Service key хранится только в игнорируемом `resource-api.local.php` и никогда не передаётся браузеру.
- `users/` остаётся runtime-хранилищем вне Git; API выбирает пользовательский каталог только после строгой проверки opaque owner.

## Шаблоны

- `templates/*.png` — переносимые BZN-проекты с превью и JSON-метаданными внутри PNG.
- `templates/*.bzn.json` — поддерживаемый запасной формат проекта.
- `templates/manifest.json` — подписи и порядок карточек; отсутствующие файлы автоматически исключаются.
- `templates/manifest.php` — динамически сканирует папку и возвращает актуальный список. Новые поддерживаемые файлы появляются даже без ручной записи в JSON.

Целевой серверный каталог: `/www/files.bsns.ru/templates`.

Файлы читает PHP-шлюз сайта редактора серверным HTTP-запросом. Браузер напрямую к этому домену не обращается, поэтому CORS не требуется.
