# files.bsns.ru

Публичное файловое хранилище BZN. Текущая рабочая область — только `templates/`; каталог `users/` этим репозиторием не изменяется.

## Шаблоны

- `templates/*.png` — переносимые BZN-проекты с превью и JSON-метаданными внутри PNG.
- `templates/*.bzn.json` — поддерживаемый запасной формат проекта.
- `templates/manifest.json` — подписи и порядок карточек; отсутствующие файлы автоматически исключаются.
- `templates/manifest.php` — динамически сканирует папку и возвращает актуальный список. Новые поддерживаемые файлы появляются даже без ручной записи в JSON.

Целевой серверный каталог: `/www/files.bsns.ru/templates`.

Файлы читает PHP-шлюз сайта редактора серверным HTTP-запросом. Браузер напрямую к этому домену не обращается, поэтому CORS не требуется.
